# Антон птичка — Android-проект

Это Android-оболочка для исходной HTML5-игры. Игра находится в `app/src/main/assets/`, запускается внутри Android WebView. JavaScript и локальное хранилище включены; проект настроен на портретную ориентацию.

## Как бесплатно получить APK через GitHub Actions

1. Создайте бесплатный аккаунт на https://github.com/ (если его ещё нет).
2. Нажмите **New repository**, назовите его `anton-ptichka-android`, выберите **Public** или **Private**, затем **Create repository**.
3. Распакуйте этот ZIP на компьютере.
4. На странице нового репозитория нажмите **Add file → Upload files**.
5. Перетащите содержимое распакованной папки (именно файлы и папки проекта, включая `.github`) в окно загрузки и нажмите **Commit changes**.
6. Откройте вкладку **Actions**. Если GitHub спросит разрешение на запуск workflows, подтвердите.
7. Дождитесь завершения задачи **Build Android APK**. Откройте её запуск и внизу страницы найдите **Artifacts**.
8. Скачайте `Anton-Ptichka-debug-apk.zip`, распакуйте его. Внутри будет `app-debug.apk`.
9. Передайте APK на Android-телефон и откройте его. Android может попросить разрешить установку приложений из этого источника.

## Важно

- Это тестовая сборка APK для установки и проверки, не готовый пакет для Google Play.
- Для Google Play позднее понадобится подписанная release-сборка в формате AAB, и нужно будет отдельно подготовить значок, скриншоты, описание и сведения о конфиденциальности.
- APK можно устанавливать вручную, но телефон может показать предупреждение, поскольку приложение не установлено из Play.
- В проект включены только предоставленные файлы игры. Сетевые разрешения приложению не нужны.
- Если сборка завершится ошибкой, пришлите скриншот или текст ошибки — разберём её.
